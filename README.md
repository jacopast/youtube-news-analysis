# 유튜브뉴스분석

시사 유튜브·방송 프로그램이 어떤 주제를 얼마나 다뤘는지, 같은 주제와 인물을 프로그램마다 어떻게 다뤘는지 살펴보는 대시보드입니다.

- **[대시보드 열기](https://jacopast.github.io/youtube-news-analysis/)**
- **[회당 평균 조회수 랭킹](https://jacopast.github.io/youtube-news-analysis/views_ranking.html)**

## 수록 범위

2026년 9월 27일 공개 스냅샷입니다. 방송일 기준 2026년 9월 9~23일 중 11일, 22개 프로그램의 수집 자료를 담았습니다. 프로그램마다 방송 여부와 수집 범위가 다릅니다. 조회수 전용 랭킹은 풀영상 조회수를 수집한 21개 프로그램·201회차를 비교합니다. MBC 뉴스데스크의 개별 리포트 집계는 해당 랭킹에서 제외합니다.

화면은 저장된 자료를 보여 주며 실시간으로 갱신되지 않습니다. 조회수는 수집 시점의 누적값입니다.

## 사용 방법

1. **9월 9일 하루 비교**: 첫 그래프에서 큰 분야별 구성을 보고, 주제를 선택해 비중 또는 분량 순으로 비교합니다. 점선은 본방 19개의 중앙값입니다. 프로그램 이름·막대를 누르면 구간표와 해당 시각의 원본 영상 링크가 열립니다.
2. **조회수 비교**: 최소 회당 조회수 필터로 표시 대상을 좁힙니다. 전용 랭킹의 `Linear` / `Log Scale`로 막대 축척을 바꿀 수 있습니다.
3. **같은 이슈의 채널별 비교**: 이슈를 고르면 전체 수집 기간의 방송 비중 순으로 가로 막대를 정렬합니다. 옆의 숫자는 비중·실제 분량·중앙값 대비 차이(%p)입니다. 점선은 비교 가능한 본방 채널들의 중앙값이며 MBC 리포트 집계는 별도 참고로 표시합니다. 기존 숫자 표는 **상세 데이터**를 펼쳐 확인합니다. 범례나 주제 띠의 다중 선택도 유지됩니다.
4. **선택 해제**: 선택한 주제를 다시 누르거나 선택 칩의 ×를 누릅니다. 빈 배경, `Esc`, `전체 색 보기`는 전체 주제 선택을 해제합니다.
5. **날짜별 변화**: 스트라타(날짜별 누적 면적 차트)의 띠 두께와 툴팁을 비교합니다. 분량과 비중 등 각 차트의 단위를 확인하세요.
6. **인물 호명과 평가**: 인물 표의 숫자는 방송 100분당 호명 빈도입니다. 칸을 누르면 판정 이유·자막 문맥·영상 시각 근거를 볼 수 있습니다. 파랑은 검수된 긍정, 빨강은 부정이며 빗금과 별표는 미검수·부분 검수를 나타냅니다.
7. **인물 호명 스트라타**: 인물 범례나 색 띠를 차례로 눌러 여러 인물을 동시에 강조합니다. 같은 인물 재클릭이나 선택 칩의 ×는 개별 해제, 빈 곳 클릭·`Esc`·`전체 색 보기`는 전체 해제입니다. `100분당` / `비중`을 바꿔도 선택은 유지됩니다.
8. **광고 품목**: 프로그램·품목·검색어로 좁히고 상세를 펼쳐 영상 근거를 확인합니다.

넓은 표와 차트는 가로로 스크롤할 수 있습니다. 데스크톱의 넓은 화면에서 비교하기 좋습니다.

## 해석할 때 확인할 점

- 수집된 자료의 분석 스냅샷이며 모든 방송의 전수 검증 결과는 아닙니다. 9월 9일은 공식 설명과 자막 표본·전환부를 대조해 재분류한 근사치입니다. 전체 영상 청취 및 모든 광고의 전수 검수 결과가 아닙니다.
- **9월 9일의 비교 범위**: 본방 19개를 비교하고 MBC 뉴스데스크 리포트 31개(자막 30개)는 별도 참고로 표시합니다. 흑백여의도에 잘못 연결된 국회 중계는 주제·호명·조회수 비교에서 제외했습니다. 민티07은 본방·휴방 미확인입니다. 미확인을 0으로 집계하지 않습니다.
- **전체 기간 이슈 비교의 분모**: 채널별 수집·분류된 방송 분량으로, 원장에 등록된 오프닝·광고·진행을 포함합니다. 채널별 집계 회차와 분모를 함께 표시합니다. 해당 이슈가 0분인 비교 채널도 중앙값에 포함하며 미집계 회차를 0으로 대체하지 않습니다.
- **9월 9일 비교의 분모**: 9월 9일 비교 그래프의 비중은 오프닝·광고·진행을 제외한 주제 분량 기준입니다. 다른 누적 그래프의 전체 분량과 분모가 다릅니다. 한겨레·오마이의 재송출, 앞 방송, 하이라이트는 본방 구간에서 제외했고 호명 집계에도 같은 시작·종료 범위를 적용했습니다.
- 호명 빈도는 지지·반대를 뜻하지 않습니다. 인물 평가 색은 검수한 문맥에만 해당하며 프로그램 전체의 정치 성향이나 출연자의 내심을 판정하지 않습니다. 미검수 항목을 중립으로 해석하지 마세요.
- 자동 자막에는 오기와 동명이인·이름 매칭 오류가 남아 있을 수 있습니다. 원문 영상과 함께 확인하세요.
- 조회수는 영상별 경과 시간이 다른 누적값입니다. 미수집을 0으로 취급하지 않으며, 방송 횟수와 수집 시점의 차이를 함께 봐야 합니다.
- 출연자별 분량은 구간 기반 추정치입니다. 9월 9일은 출연 구간을 재확인한 MBC 라디오 2개만 반영하며 다른 프로그램의 출연자 분량은 보류했습니다. 음성 화자 분리로 측정한 실제 발언 시간이 아닙니다.
- 광고 품목은 확인된 일부 목록입니다. 미등록이 광고 0회·0분을 의미하지 않으며, 광고와 진행 구간의 세부 분류도 보완 중입니다.

## 파일과 열람

| 파일 | 내용 |
|---|---|
| `index.html` | 데이터가 내장된 채널 의제 대시보드 |
| `views_ranking.html` | 회당 평균 조회수 전용 랭킹 |
| `README.md` | 사용 방법과 해석 범위 |
| `.nojekyll` | GitHub Pages 정적 파일 제공 설정 |

HTML을 내려받아 브라우저로 직접 열 수도 있습니다. 대시보드는 약 21MB이므로 첫 로딩에 시간이 걸릴 수 있습니다. 글꼴과 랭킹의 스타일 도구, 원문 영상 링크에는 인터넷 연결이 필요합니다. 공개 저장소에는 열람용 결과물만 포함합니다.

영상·방송·인용 자막의 권리는 각 권리자에게 있습니다. 이 저장소는 원본 영상과 전체 자막 파일을 배포하지 않습니다.
