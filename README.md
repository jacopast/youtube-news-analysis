# 유튜브뉴스분석

시사 유튜브·방송 프로그램이 어떤 주제를 얼마나 다뤘는지, 같은 주제와 인물을 프로그램마다 어떻게 다뤘는지 살펴보는 대시보드입니다.

- **[대시보드 열기](https://jacopast.github.io/youtube-news-analysis/)**
- **[회당 평균 조회수와 회차별 추이](https://jacopast.github.io/youtube-news-analysis/#p-views)**

## 수록 범위

2026년 10월 17일(뉴욕시간) 공개 스냅샷입니다. 방송일 기준 2026년 9월 1일~10월 9일 중 31일, 30개 프로그램을 분석 대상으로 등록했습니다. 기존 24개에 최경영TV·새날·고성국TV·주간 뉴스타파·김용민 브리핑·신의한수 긴급 라이브뉴스를 추가했습니다. 신규 6개는 성숙한 본방송 표본 각 3편의 조회수만 먼저 반영했으며, 전체 기간 수집과 자막·의제·호명 분석은 진행 중입니다.(추석 연휴 9/24~25, 개천절 10/3, 일요일 10/4는 대부분 휴방, 대체공휴일 10/5는 일부 휴방). 프로그램마다 방송 여부와 수집 범위가 다릅니다. 9월 28일의 추출된 호명 문맥은 검수를 마쳤고, 9월 29일~10월 1일은 일부 문맥을 검수했습니다. 10월 2일~10월 8일 방송분의 인물 호명 평가는 검수 대기입니다(부분 검수·미검수로 표시). 조회수는 대시보드의 '회당 평균 조회수'와 채널별 '회차별 조회수 추이'에서 봅니다(예전 랭킹 주소는 이 섹션으로 연결됩니다). 각 섹션은 제목을 눌러 접고 펼 수 있습니다.

10월 9일은 뉴스하이킥·뉴스데스크·정준희의 논 3회차의 전체 자막에서 인물·논점을 새로 발굴해 반영했습니다. 뉴스하이킥의 이극로·주시경은 공식 개별 자료와 당일 원문을 대조한 좌표만 추가했습니다. 뉴스데스크는 기자·정치인의 부분일치와 야구 중 트럼프 자막 오탐을 제외했고, 정준희의 논에서는 철학 소개와 인물 칭찬을 구분했습니다. 실제 검수 수와 남은 범위는 대시보드의 집계·원자료 확인표에 표시합니다.

새 인물 총56명의 집계는 각 검토한 원문에 한정하며 다른 회차는 **미조사**입니다. 미조사는 언급0이 아닙니다. 신규 인물의 전체100분당 값은 검토한 회차의 본론만 분모로 사용합니다. 같은 날 다른 본방11개(신규 새날·고성국TV 포함)는 조회수 확인·주제/신규 인물 검수 대기이며, 전편 재송출1개는 새 본방 집계에서 제외했습니다. 불명확한 STT 인물·정규명·직함은 별도로 확인 중이며 이전 회차도 최신일부터 역순으로 재점검합니다.

최경영TV 10월 7일 본방송은 수집 시점 조회수 47,595회와 자막을 확인해 등록했습니다. 주제·인물·광고의 의미 검수는 대기 중입니다.

주간 뉴스타파 10월 8일 본방송은 수집 시점 조회수 53,050회와 자막을 확인해 등록했으며 주제·인물·광고의 의미 검수는 대기 중입니다. 뉴스하이킥 10월 9일 호명은 후속 47건까지 문맥 검수해 평가에 반영했습니다.

화면은 저장된 자료를 보여 주며 실시간으로 갱신되지 않습니다. 조회수는 수집 시점의 누적값입니다.

## 사용 방법

1. **9월 9일 하루 비교**: 첫 그래프에서 큰 분야별 구성을 보고, 주제를 선택해 비중 또는 분량 순으로 비교합니다. 점선은 본방 19개의 중앙값입니다. 프로그램 이름·막대를 누르면 구간표와 해당 시각의 원본 영상 링크가 열립니다.
2. **조회수 비교**: 최소 회당 조회수 필터로 표시 대상을 좁힙니다. 전용 랭킹의 `Linear` / `Log Scale`로 막대 축척을 바꿀 수 있습니다.
3. **같은 이슈의 채널별 비교**: 이슈를 고르면 전체 수집 기간의 방송 비중 순으로 가로 막대를 정렬합니다. 옆의 숫자는 비중·실제 분량·중앙값 대비 차이(%p)입니다. 점선은 비교 가능한 본방 채널들의 중앙값이며 MBC 리포트 집계는 별도 참고로 표시합니다. 기존 숫자 표는 **상세 데이터**를 펼쳐 확인합니다. 범례나 주제 띠의 다중 선택도 유지됩니다.
4. **선택 해제**: 선택한 주제를 다시 누르거나 선택 칩의 ×를 누릅니다. 빈 배경, `Esc`, `전체 색 보기`는 전체 주제 선택을 해제합니다.
5. **날짜별 변화**: 스트라타(날짜별 누적 면적 차트)의 띠 두께와 툴팁을 비교합니다. 분량과 비중 등 각 차트의 단위를 확인하세요.
6. **인물 호명과 평가**: 인물 표와 호명 스트라타는 선택 기간·프로그램에서 호명이 많은 상위 30명만 표시합니다. 필터를 바꾸면 순위를 다시 계산합니다. 인물 표의 숫자는 방송 100분당 호명 빈도이며, 칸을 누르면 날짜별 집계와 방송 원본 링크를 볼 수 있습니다. 개별 호명·자막 문맥·판정 사유는 공개하지 않고 내부 원자료로 보존합니다. 파랑은 검수된 긍정, 빨강은 부정이며 빗금과 별표는 미검수·부분 검수를 나타냅니다.
7. **인물 호명 스트라타**: 인물 범례나 색 띠를 차례로 눌러 여러 인물을 동시에 강조합니다. 같은 인물 재클릭이나 선택 칩의 ×는 개별 해제, 빈 곳 클릭·`Esc`·`전체 색 보기`는 전체 해제입니다. `100분당` / `비중`을 바꿔도 선택은 유지됩니다. 비중의 분모는 표시된 상위 30명의 그날 호명 합입니다.
8. **광고 품목**: 프로그램·품목·검색어로 좁히고 상세를 펼쳐 영상 근거를 확인합니다.

넓은 표와 차트는 가로로 스크롤할 수 있습니다. 데스크톱의 넓은 화면에서 비교하기 좋습니다.

## 해석할 때 확인할 점

- 수집된 자료의 분석 스냅샷이며 모든 방송의 전수 검증 결과는 아닙니다. 9월 9일은 공식 설명과 자막 표본·전환부를 대조해 재분류한 근사치입니다. 전체 영상 청취 및 모든 광고의 전수 검수 결과가 아닙니다.
- **9월 9일의 비교 범위**: 본방 19개를 비교하고 MBC 뉴스데스크 리포트 31개(자막 30개)는 별도 참고로 표시합니다. 흑백여의도에 잘못 연결된 국회 중계는 주제·호명·조회수 비교에서 제외했습니다. 민티07은 본방·휴방 미확인입니다. 미확인을 0으로 집계하지 않습니다.
- **전체 기간 이슈 비교의 분모**: 채널별 수집·분류된 방송 분량으로, 원장에 등록된 오프닝·광고·진행을 포함합니다. 채널별 집계 회차와 분모를 함께 표시합니다. 해당 이슈가 0분인 비교 채널도 중앙값에 포함하며 미집계 회차를 0으로 대체하지 않습니다.
- **9월 9일 비교의 분모**: 9월 9일 비교 그래프의 비중은 오프닝·광고·진행을 제외한 주제 분량 기준입니다. 다른 누적 그래프의 전체 분량과 분모가 다릅니다. 한겨레·오마이의 재송출, 앞 방송, 하이라이트는 본방 구간에서 제외했고 호명 집계에도 같은 시작·종료 범위를 적용했습니다.
- 호명 빈도는 지지·반대를 뜻하지 않습니다. 인물 평가 색은 검수한 문맥에만 해당하며 프로그램 전체의 정치 성향이나 출연자의 내심을 판정하지 않습니다. 미검수 항목을 중립으로 해석하지 마세요.
- 자동 자막에는 오기와 동명이인·이름 매칭 오류가 남아 있을 수 있습니다. 원문 영상과 함께 확인하세요.
- 조회수는 영상별 경과 시간이 다른 누적값입니다. 미수집을 0으로 취급하지 않으며, 방송 횟수와 수집 시점의 차이를 함께 봐야 합니다.
- 출연자별 분량은 구간 기반 추정치입니다. 9월 9일은 출연 구간을 재확인한 MBC 라디오 2개만 반영하며 다른 프로그램의 출연자 분량은 보류했습니다. 음성 화자 분리로 측정한 실제 발언 시간이 아닙니다.
- 광고 품목은 확인된 일부 목록입니다. 미등록이 광고 0회·0분을 의미하지 않으며, 광고와 진행 구간의 세부 분류도 보완 중입니다.

HTML을 내려받아 브라우저로 직접 열 수도 있습니다. 대시보드는 약 49MB이므로 첫 로딩에 시간이 걸릴 수 있습니다. 글꼴과 랭킹의 스타일 도구, 원문 영상 링크에는 인터넷 연결이 필요합니다. 공개 저장소에는 열람용 결과물만 포함합니다.

영상·방송·인용 자막의 권리는 각 권리자에게 있습니다. 이 저장소는 원본 영상과 전체 자막 파일을 배포하지 않습니다.

10월 17일 추가 검수: 10/9 호명·호불호 27건을 반영했습니다. 새날 10/9는 성숙 조회수와 전체 자막 원자료를 보충해 분류 대기로 표시하며, 전체 인물·의제 분석은 미완료입니다.
